# VPhone Hub — виртуальный телефон-конструктор

Приложение для Android: панель управления **виртуальными машинами**: создание ВМ
с настраиваемой памятью/CPU/диском, встроенный shell-терминал для кодинга,
ИИ-ассистент, подключение аккаунтов/почты и планировщик автоматизаций.
Задумка — «второй смартфон» внутри вашего: окружение и данные живут в ВМ, а не на основном телефоне.

## Возможности (v0.1)

- **Менеджер ВМ** — создание профилей: имя, тип ОС (linux / custom / android / windows),
  RAM 512–8192 МБ, 1–8 ядер, 4–256 ГБ диска; запуск/остановка/удаление.
  Память профиля проверяется против реального ОЗУ устройства.
- **Терминал** — встроенная shell-консоль (реальный `sh` на устройстве) — база для Termux-стиля работы с кодом.
- **ИИ-ассистент** — чат через любой OpenAI-совместимый API (по умолчанию OpenRouter,
  модель Mistral). Ключ хранится локально в настройках приложения.
- **Аккаунты и почта** — реестр подключённых аккаунтов (email/соцсети) + интерфейс
  `MailClient` (IMAP/SMTP) для интеграции почты.
- **Автоматизации** — правила «имя + shell-команда + интервал в минутах», выполняются фоновым движком.
- **Termux-движок** — запуск Linux-окружений (Debian/Alpine) через `proot-distro` внутри Termux.

## Архитектура

```
app/src/main/java/com/vphone/hub/
├── MainActivity / VmAdapter        # дашборд: список ВМ, статистика ОЗУ
├── VmCreateActivity                # конструктор ВМ (слайдеры RAM/CPU/диск)
├── VmDetailActivity                # запуск/остановка, переход в терминал
├── VmManager / VmProfile / VmRepository   # модель, лимиты, JSON-хранилище
├── TerminalActivity                # встроенный shell
├── engine/TermuxEngine             # адаптер запуска ОС через Termux (proot)
├── ai/AiClient + ChatActivity      # OpenAI-совместимый чат-клиент
├── accounts/AccountStore + AccountsActivity
├── mail/MailClient                 # IMAP/SMTP-интерфейс (расширение)
└── automations/AutomationEngine    # фоновый планировщик shell-правил
```

## Реалистичные ограничения (честно)

- **RAM ВМ ограничена памятью телефона** — «ухуенной» памяти не бывает: профиль
  больше 8 ГБ бессмысленен без соответствующего устройства.
- **Android внутри Android** только с root или на платформах с виртуализацией
  (Android 13+ pKVM); без этого — см. termux-scripts/README.md.
- **Windows x86** запускается через QEMU-эмуляцию в Termux и очень медленна
  (это свойство железа, не приложения).

## Быстрый старт

1. Откройте проект в Android Studio (JDK 17), соберите `assembleDebug`.
2. Установите Termux (F-Droid) и выполните `bash termux-scripts/setup.sh`.
3. В приложении: создайте ВМ → «Запустить» (Linux-типы стартуют в Termux),
   «Терминал» для работы с кодом, «Чат ИИ» → ⚙ введите API-ключ.

## CI

`.github/workflows/android.yml` собирает debug-APK на каждый push.

## Дорожная карта

- Реальная IMAP/SMTP синхронизация почты (Jakarta Mail)
- Просмотр/загрузка образов ВМ (Android-x86, QEMU-образы) и загрузчик
- Синхронизация окружения «телефон → ВМ»: экспорт контактов/файлов/аккаунтов
- Веб-дашборд управления ВМ с телефона

## Веб-панель

Статическая веб-панель (`docs/index.html`) публикуется на GitHub Pages:
**https://palcikia-crypto.github.io/vphone-hub/**

Внутри: интерфейс «виртуального андроида» в браузере, менеджер профилей ВМ,
демо-shell, ИИ-чат (OpenRouter-совместимый API, ключ хранится локально),
реестр аккаунтов и планировщик автоматизаций. Браузер не может запустить
настоящую ОС — реальный запуск Linux-окружений делает Android-приложение.
