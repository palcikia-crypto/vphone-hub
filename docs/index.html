⚙️ О системе

VPhone Hub Web · v0.1
Веб-панель проекта «виртуальный телефон»: управление профилями ВМ, демо-терминал, ИИ-чат, аккаунты, автоматизации.
Реальный запуск ОС
Android-приложение из репозитория запускает Debian/Alpine через Termux (proot-distro). Android-в-Android и Windows — только с root/виртуализацией или через медленную QEMU-эмуляцию.
Приватность
Все данные (ВМ, аккаунты, ключ ИИ) хранятся только в localStorage вашего браузера и никуда не отправляются, кроме запросов к выбранному ИИ-API.

Что это

Веб-панель проекта VPhone Hub — «виртуальный телефон» в браузере: интерфейс, похожий на Android-лаунчер, менеджер виртуальных машин и инструменты.

Возможности

  • Создание ВМ: тип ОС, RAM до 8 ГБ, ядра, диск
  • 💽 Готовые ОС уже внутри панели (v86): FreeDOS, TinyCore, Alpine, Android-x86 1.6 (эксп.) + свой ISO/IMG
  • Демо-shell: команды help, vm list, vm start, sysinfo…
  • ИИ-чат через OpenAI-совместимый API (ключ — только локально)
  • Аккаунты и почта — реестр подключений
  • Автоматизации — правила «команда + интервал»

Ограничения браузера

Эмулятор v86 запускает настоящие x86-ОС программной эмуляцией — без аппаратной виртуализации это медленно. Хорошая новость: образы готовых систем (FreeDOS, TinyCore, Alpine, Android-x86 1.6) уже встроены в саму панель и лежат на GitHub Pages — ничего скачивать не нужно. Но пределы WASM честны: современный Android-x86, Windows 7+ и тяжёлые графические системы в браузере не запустятся; полноценный Android — это само Android-приложение VPhone Hub + его Termux-движок.

Данные

ВМ, аккаунты и ключи хранятся в localStorage этого браузера.
